# Outer Loop page-icon observation

Outer Shell and Outer Loop cooperate to discover icons for apps that do not have
an explicit `iconPath`. The protocol belongs to the two products' navigation
integration. It is the same whether the Outer Shell home screen is rendered by
native Outerframe content or by a web view.

## Navigation request

Outer Loop advertises support to web documents at document start:

```javascript
window.outerLoopPageIconObservationSupported = true
```

When that value is present, Outer Shell replaces a normal iconless-app
navigation with:

```text
outerloop://observe-page-icon?url=<percent-encoded-target>&callback=<percent-encoded-callback>
```

Native Outer Shell content emits the same URL without feature detection. Outer
Loop intercepts the URL before WebKit or Outerframe content tries to load it,
retains the observation for the destination tab, and navigates to `url` using
its normal TCP or Unix-socket routing.

`url` may use `http`, `https`, or `http+unix`. `callback` must use `http` or
`https`, must address an Outer Loop internal or proxy host, and must have the
path `/api/icon-observation`.

## Discovery and callback

For a web destination, Outer Loop checks document `link` elements after the
page finishes loading, in this order:

1. `shortcut icon`
2. `icon`
3. `apple-touch-icon`
4. `apple-touch-icon-precomposed`

If none is declared, it tries `/favicon.ico`. Outer Loop downloads the selected
resource through the tab's existing connection, decodes it, scales it to fit
within 512 by 512 pixels, converts it to PNG, and sends it as the body of an
HTTP `POST` to `callback` with `Content-Type: image/png`.

For an Outerframe destination, Outer Loop uses the app's presentation icon and
sends it through the same PNG callback. From Outer Shell's perspective the
source of the discovered icon makes no difference.

The callback URL contains an opaque 128-bit capability generated by Outer
Shell. The capability is bound to one frontend in the primary user registry.
Outer Shell accepts at most 48 KiB, verifies that the body is a PNG no larger
than 4096 by 4096 pixels, and ignores the observation if the frontend acquired
an explicit icon in the meantime. A valid discovered icon is stored under the
Outer Shell user data root and its path is persisted as the frontend's icon.

## Compatibility

An older Outer Loop does not advertise the web feature and the web home screen
navigates directly to the app. Native Outer Shell navigation requires an Outer
Loop version that recognizes the custom URL; the custom URL is never sent to
the destination app itself.
