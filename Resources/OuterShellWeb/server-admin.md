# Server administration with Outer Shell

This workspace manages this server through Outer Shell. You are already on the target server; do not SSH elsewhere unless requested.

Use the outer-shell skill to install, register, run, and troubleshoot apps. Read https://outershell.org/api/ for current integration instructions.

Keep useful management scripts and notes here. Apps, experiments, repositories, and data can live elsewhere; do not move them into this folder unnecessarily. Inspect existing services and registrations, preserve unrelated services and data, and verify that each app responds and appears in Outer Shell.
